# Команда на iPhone: выгрузка из Apple Health

Команда собирает шаги и сон за последние 2 дня и кладёт их в `iCloud Drive/Floor/health.json` (режим Mac) или отправляет на сервер (режим Fly). Делается один раз, примерно 15 минут.

> Названия действий даны для русского и английского интерфейса iOS. В разных версиях iOS формулировки могут немного отличаться.

## 0. Подготовка

1. Убедись, что Fitbit пишет шаги и сон в «Здоровье»: Здоровье → Обзор → Шаги / Сон должны показывать данные.
2. В iCloud Drive создай папку `Floor`.

## 1. Команда «Floor Export»

Приложение «Команды» → `+` → назови `Floor Export`.

### Шаги

1. **Найти образцы здоровья** (*Find Health Samples*)
   - Тип: **Шаги**
   - Дата начала: **за последние 2 дня**
   - Группировать по: **День**
   - Сортировка: **Дата начала**, по возрастанию
2. **Повторить с каждым** (*Repeat with Each*) по результату:
   - **Словарь** (*Dictionary*): `date` = Дата начала (формат `yyyy-MM-dd`), `count` = Значение
   - **Добавить в переменную** `steps`
3. Конец повтора.

### Сон

4. **Найти образцы здоровья**
   - Тип: **Анализ сна** (*Sleep Analysis*)
   - Дата начала: **за последние 2 дня**
5. **Повторить с каждым**:
   - **Словарь**: `start` = Дата начала (ISO 8601), `end` = Дата окончания (ISO 8601), `value` = Значение
   - **Добавить в переменную** `sleep`
6. Конец повтора.

### Сборка JSON

7. **Текущая дата** → **Форматировать дату** ISO 8601 → переменная `now`.
8. **Словарь**:
   - `schema` (число) = `1`
   - `generated_at` (текст) = `now`
   - `tz_offset` (текст) = **Форматировать дату** текущей даты по шаблону `xxx` (получится `+05:00`)
   - `steps` (массив) = переменная `steps`
   - `sleep` (массив) = переменная `sleep`

### Куда отправить

**Режим Mac:**

9. **Сохранить файл** (*Save File*) → `iCloud Drive/Floor/health.json`, **«Спросить, куда сохранить» — выкл**, **«Перезаписывать» — вкл**.

**Режим Fly.io** (вместо шага 9):

9. **Получить содержимое URL** (*Get Contents of URL*)
   - URL: `https://<твоё-приложение>.fly.dev/ingest`
   - Метод: **POST**
   - Заголовки: `Authorization` = `Bearer <INGEST_TOKEN>`
   - Тело запроса: **Файл** → результат шага 8

## 2. Автоматизация

Команды → **Автоматизация** → `+` → **Приложение** → **Telegram** → **Открыто**.

- Действие: **Запустить команду** → `Floor Export`.
- **Запускать сразу** (*Run Immediately*) — вкл.
- **Уведомлять при запуске** — выкл.

Почему не «по времени»: когда iPhone заблокирован, iOS не даёт читать данные «Здоровья». Telegram ты открываешь только на разблокированном телефоне, так что триггер надёжный. Команда перезаписывает файл, поэтому частый запуск ничего не ломает.

## 3. Проверка

1. Запусти команду вручную.
2. На Маке: `cat ~/Library/Mobile\ Documents/com~apple~CloudDocs/Floor/health.json`.
3. В файле должны быть массивы `steps` и `sleep`. Если Fitbit пишет сон без стадий, в `value` будет одно значение вроде «Сон» — это нормально, парсер это понимает.

## Если что-то не так

| Симптом | Что проверить |
|---|---|
| Пустой `sleep` | Разрешения: Здоровье → Доступ к данным → Команды → Сон |
| Файл не появляется на Маке | Системные настройки → Apple ID → iCloud Drive включён; папка `Floor` скачана |
| Автоматизация просит подтверждение | Включи «Запускать сразу». Если опции нет — запасной вариант: автоматизация «Время суток» на 10:00 и 22:00 |
